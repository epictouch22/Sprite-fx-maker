Холст и экспорт

MP4/H.264 не хранит прозрачность. Для настоящего alpha используйте WebM; для iPhone/монтажа в MP4 — chroma key.
Клик по холсту меняет точку появления/центр пирамиды. Счётчик позиционируется отдельно через X/Y.
v2.8: MOV α теперь экспортируется прямо из редактора одним нажатием. ZIP и повторная загрузка кадров больше не нужны. Первый запуск только скачивает FFmpeg.wasm.
Нет спрайтов — можно использовать только счётчик или загрузить PNG/JPG/WebP
