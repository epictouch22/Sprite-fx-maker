# Sprite FX Maker

Однофайловый браузерный редактор анимированных спрайтовых эффектов для Shorts/Reels/TikTok и монтажа.

## Возможности

- появление и растворение спрайтов;
- пирамиды с автоподгонкой размера под кадр;
- случайный разброс объектов из точки;
- несколько спрайтов с рандомным выбором;
- glow / подсветка объектов;
- счётчики и таймеры с анимацией значений;
- пользовательские TTF/OTF/WOFF/WOFF2 шрифты;
- пресеты;
- экспорт PNG-кадра и WebM-анимации;
- форматы 9:16, 16:9 и 1:1.

## Запуск

Откройте `index.html` в современном Chrome или Edge. Никакой сборки и установки зависимостей не требуется.

## GitHub Pages

Проект полностью статический, поэтому `index.html` можно публиковать напрямую через GitHub Pages.

## GitHub Pages

Репозиторий настроен на автоматическую публикацию статического сайта через GitHub Pages при каждом push в `main`.
